# Sample-agnostic utils

This directory contains functions implementing **sample-agnostic** annotation and clustering quality methods, i.e. methods that do not explicitly account for sample/donor identity, in contrast to **scTypeEval** and **MetaNeighbor**.

| **Name** | **Source** | **Description** | **Comparison** |
|---|---|---|---|
| **MetaNeighbor** | [GitHub](https://github.com/gillislab/MetaNeighbor) · [Nature Communications](https://www.nature.com/articles/s41467-018-03282-0) | Evaluates cross-dataset or cross-donor replicability of individual cell types. | Designed to evaluate which genes distinguish cell types across datasets rather than to benchmark annotation quality directly. |
| **SCCAF** | [GitHub](https://github.com/SCCAF/sccaf) · [Nature Methods](https://www.nature.com/articles/s41592-020-0825-9) | Uses self-projection and classification confusion to assess label separability and guide cluster refinement. | Can provide information about clustering reproducibility and label separability, but is primarily designed to determine appropriate clustering granularity rather than evaluate annotation quality. |
| **CellHint** | [GitHub](https://github.com/Teichlab/cellhint) · [Cell](https://www.cell.com/cell/fulltext/S0092-8674(23)01312-0) | Identifies one-to-one, one-to-many, and many-to-one relationships between annotations across datasets. | Does not directly evaluate annotation quality; focuses on identifying correspondences between annotations across datasets. |
| **VICTOR** | [GitHub](https://github.com/Charlene717/VICTOR) · [ScienceDirect](https://www.sciencedirect.com/science/article/pii/S2001037024002873) | Quantifies the reliability of cell-type annotations by comparing reference and query datasets. | Primarily evaluates annotation consistency relative to a reference rather than sample-aware consistency across independent samples. |
| **popV** | [GitHub](https://github.com/YosefLab/popV) · [Nature Genetics](https://www.nature.com/articles/s41588-024-01993-3) | Generates consensus cell-type annotations from multiple annotation methods. | Evaluates agreement between annotation methods and produces consensus labels rather than directly measuring annotation quality or inter-sample consistency. |
| **Anticor_features** | [Bitbucket](https://bitbucket.org/scottyler892/anticor_features/src/main/) · [Nature Communications](https://www.nature.com/articles/s41467-023-43406-9) | Uses anti-correlation-based feature selection to identify informative genes for cell-type discrimination. | Does not use sample information and is primarily a feature-selection approach rather than an annotation-quality metric. |
| **Sc-SHC** | [GitHub](https://github.com/igrabski/sc-SHC) · [Nature Methods](https://www.nature.com/articles/s41592-023-01933-9) | Uses hypothesis testing within a hierarchical procedure to assess and refine clustering structure. | Does not use sample information and is primarily designed for hierarchical clustering and cluster validation rather than annotation evaluation. |
